# V8 Page 1 / Animation 1 — Build Prompt

## Purpose

Build Page 1 and Animation 1 as the evidence-intake and progressive source-processing chapter of the Orchid Meridian investigation. The story must show how seven sources become reliable case memory without overwhelming the audience at frame start.

## Storyline

1. The analyst opens the case and supplies seven prepared sources.
2. The Document Intelligence Agent parses three short documents.
3. The same agent processes the long KYC profile and bill of lading through `OCR → LLM → Validate`.
4. The Context Agent reconstructs the email explanation and identifies the missing credit note.
5. The Data Analyst queries transaction and customer-profile data.
6. The Orchestrator receives the completed seven-source memory and enables the External Web Agent for Animation 2.

## Required frame design

- Frame 1: short-document batch; animated file tray and scanner; publish invoice, contract and customs results progressively.
- Frame 2: long documents; show only the animated `OCR → LLM → Validate` workbench in the main canvas. Do not repeat KYC/Bill-of-Lading result cards or a second Document Intelligence handoff below it.
- Frame 3: email context; publish chronology, stated purpose and the missing-credit-note evidence gap.
- Frame 4: internal data; show transaction SQL and profile/related-client SQL as distinct actions and outputs.

## Dynamic dialogue

The left panel contains the stable workforce roster. Only the active agent expands a speech bubble. Reveal `TASK`, `ACTION`, `REASONING SUMMARY`, and `OUTPUT / HANDOFF` word by word. The handoff must name the exact agent and task in the following frame.

## Main-canvas contract

- Start each frame with retained-result chips and one active-work header.
- Reveal the current tool/action before structured output.
- Keep every component relevant to the current frame only.
- Collapse completed work into retained-result chips when the presenter advances.
- Do not duplicate the authoritative left-panel output/handoff in the main canvas.

## Content consistency

Maintain these facts: office-stationery NOB; expected activity USD 45,000/month; USD 486,000 observed over eight days; Aster Peak FZE; invoice narrative of premium copy paper; shipping/customs evidence of CNC cutting equipment; HS 8461.50; missing credit note.

## Acceptance checks

- Four frames account for all seven sources.
- Frame 2 visibly reads `OCR → LLM → Validate` and contains no visible VLM label.
- Frame 2 contains no KYC result card, bill-of-lading result card or duplicate Document Intelligence handoff.
- External Web Agent becomes ready only after both SQL outputs.
- Every handoff matches the next frame’s active agent.
- No private chain-of-thought is exposed.
