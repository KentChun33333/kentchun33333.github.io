# V8 Page 1 / Animation 1 — Presenter and QA Notes

## Presenter storyline

Page 1 establishes that agentic investigation begins with controlled evidence preparation. The key message is not “AI read files”; it is “specialized agents converted heterogeneous sources into a traceable case memory.”

## Talk points by frame

### Frame 1 — Short documents

- One Document Intelligence Agent owns the task.
- OCR and VLM are lightweight tools for digitally legible invoice, contract and customs pages.
- Three results appear one at a time so the audience can see what each source contributes.

### Frame 2 — Long documents

- Long files follow a different path: OCR reconstructs page order, LLM structures the extracted content, and validation challenges field consistency.
- The animated scanner, counters and field panels are the result story for this frame.
- The left dialogue carries the authoritative output and handoff; do not narrate duplicate result cards.

### Frame 3 — Email context

- The Context Agent distinguishes the customer’s explanation from evidence actually supplied.
- The absent credit note is retained as an evidence gap, not silently inferred.

### Frame 4 — Internal data

- The Data Analyst performs two separately visible SQL tasks: transaction behavior and customer/related-client profile retrieval.
- Only when both are complete is the External Web Agent ready for the next animation.

## Frame-alignment checklist

- Active workforce row, dialogue, main-canvas header, action and next handoff describe the same frame.
- Previous-frame details appear only as retained chips.
- No result is shown before the action that creates it.
- The next-delegation text exactly matches the following frame.
- Confidence, source type and evidence gaps remain visible where decision-relevant.

## Content checks

- Do not call ledger/profile extraction OCR.
- Do not show VLM in frame 2.
- Do not treat the customer email claim as verified evidence.
- Preserve the low-confidence cargo-description issue.
- End with case memory ready for the Orchestrator and External Web Agent.
