# V8 Page 3 / Animation 3 — Build Prompt

## Purpose

Build Page 3 as the human-review, reporting and targeted-refinement chapter. Animation 3 must show how an analyst’s instruction extends the case without silently changing established findings or expanding scope beyond counterparty #2.

## Storyline

1. The analyst reviews the STR draft, recommendation, provenance and key risks.
2. The analyst directs a focused review of counterparty #2, Vale Industrial Holdings.
3. Orchestrator constrains the request and delegates transaction isolation.
4. Data Analyst isolates the USD 118,400 payment and missing commercial evidence.
5. Entity Resolver and External Web Agent resolve the common director and simulated adverse-news lead.
6. Evidence QA distinguishes registry fact from an unverified news allegation.
7. Risk + Narrative updates the report, recommendation and provenance for human filing review.

## Animation 3 frames

- Frame 1: targeted human scope.
- Frame 2: counterparty #2 transaction isolation.
- Frame 3: director and simulated adverse-news research.
- Frame 4: relationship reconstruction and validation gap.
- Frame 5: report update and human filing decision.

## Dynamic dialogue and canvas

- Follow `OR → DA → ER/EW → QA → RN`.
- Reveal one structured active-agent dialogue word by word.
- Keep the main canvas limited to the current frame’s evidence and action.
- Preserve previous results as chips.
- Ensure each output/handoff names the exact next agent and task.
- Clearly label bank facts, registry facts and simulated unverified news.

## Micro reports as appendices

- Treat every key-risk micro report as an appendix to the STR, not as a competing main report.
- Label them `Appendix KR-01`, `Appendix KR-02`, and so on.
- Each appendix contains executive conclusion, evidence chain, source register, limitations and next action.
- Main-page risk cards may open an appendix, but the primary narrative, recommendation and provenance stay in the main report.
- Printing/saving must place appendices after the main report.

## Acceptance checks

- Five refinement frames preserve the approved scope.
- Counterparty #2 is not promoted before identity and evidence validation.
- The adverse-news allegation remains an open-source lead requiring independent validation.
- The final handoff is a human filing decision.
- Recommendation and provenance appear once in the main report.
- Micro reports are consistently labelled and structured as appendices.
