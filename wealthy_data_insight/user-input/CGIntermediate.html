Multi-Step Chain Logic & Algorithm

Controls how the system follows connections between clients. When chain linking is enabled, the system doesn't just find direct links — it follows a chain of connections (like A→B→C) to uncover broader clusters. The depth setting determines how many steps to follow. The algorithm setting determines the method used to define group boundaries once all connections are mapped.

Analytics Enrichments

Select the visualizations to generate alongside your grouping results. Each provides a different analytical lens on the identified client clusters.

Network Map

Interactive map showing all clients, shared entities, and relationship connections. Circle size = client AUM, line thickness = connection strength. Groups outlined in color.

Group Comparison Bar Chart

Horizontal bar chart comparing groups by selected metric (client count, AUM, link count, or risk score). Sorted for immediate ranking visibility.

Relationship Flow Diagram

Flow diagram showing how different relationship sources feed into final group assignments. Reveals which link types dominate each cluster.

Group Evolution Timeline

Shows how groups form, grow, merge, or dissolve over time. Identifies emerging clusters and stable core groups.

AUM Concentration Chart

Nested donut chart showing how assets are distributed across groups. Flags concentration risk when one group holds a disproportionate share.

Bridge & Connector Map

Identifies key clients who connect otherwise separate groups. Critical for understanding network vulnerabilities and referral potential.
