03 · 誰決定上限，誰決定用法

伺服器能力 ≠ 代理設定

問題

上下文視窗、影像能力、速率限制與連線行為因部署而異。寫死數字 → 換部署即超限；盲目重送 → 重複輸出或卡住。

核心想法

能力（視窗 W、影像）是部署事實，向伺服器查詢；策略（輸出量、保留量、分塊）恆受 W 限制。速率共用一份預算，失敗僅做有限次乾淨重試。

依據

本機 /models 回報 n_ctx = 62,536，Qwen 設定 60,000：同為本機小模型，視窗不同。恢復行為有回歸測試（③）。

問題：同一份程式跑在不同部署

  • 視窗不同：模型名稱不決定 W。寫死 60k → 32k 部署長任務中途超限，反之浪費。壓縮門檻、保留量、文件分塊皆由 W 推算 → W 錯則全錯。
  • 速率限制：主代理、文件子代理、壓縮呼叫共用供應者配額 → 各自重試同時撞 429。
  • 串流中斷：傳輸層重播或換後端 → 輸出重複或拼接；半截回覆可能被當成完整答案。

核心想法：查詢能力、共用預算、乾淨重試

W 是部署事實，非模型名稱常數。 OpenAI／Strata 向伺服器查；Qwen38 預設 60,000，取自使用者提供的部署設定，非即時偵測。換部署須確認兩後端都放得下，必要時覆寫。
能力、連線與策略的分工
類別內容目前的來源與規則

能力更新時機

Agent.run 開始、文件預算規劃、上下文超限後：OpenAI 重新偵測，Qwen 重讀明確設定。其餘讀快照。

無有效視窗時

OpenAI 缺有效視窗或找不到所選模型 → 報錯。Qwen 不需模型清單，用內建 60k 或覆寫；無效覆寫（0、負值）→ 報錯。內建值 ≠ 伺服器已驗證接受。

兩個環境直接啟動，無需另填主機或金鑰

# 本機 Strata，保留原本預設
uv run kentc-agent "Your task"

# Qwen coordinator 優先，串流開始前失敗可切 LiteLLM
uv run kentc-agent --provider qwen38 "Your task"

# Qwen LiteLLM 優先，備援為 coordinator
uv run kentc-agent --provider qwen38 --qwen-backend litellm "Your task"

主機、API key、模型名稱集中於 config/qwen38.yaml 的 coordinator／litellm 兩段（各含 base_url、api_key、model）；改後重啟 CLI/Studio，免改 Python。wheel 內為 kentc_agent/deployment_config/qwen38.yaml → 更新須重建／重裝。優先序：明確連線設定 > 後端環境變數 > 此檔；切換環境時移除過時通用覆寫。Studio 共用，以 KENTC_AGENT_PROVIDER=qwen38 選 Qwen。

部署與憑證限制：YAML 含復原的 coordinator token；移出 Python ≠ 秘密管理 → 設定檔與建置產物須私有，外洩或到期即輪替，token 不抄到本頁。LiteLLM 沿用原客戶端預設 key。TLS 驗證不關；前提：內網、企業 CA 信任、伺服器接受憑證（不保證永久有效）。

共享 TPM 與乾淨串流重試

串流保持啟用，畫面 delta 僅暫時。截斷、中斷串流、無效工具 JSON 於保存／執行前拒絕；工作流程／Studio JSON 另驗 schema 與 checks。不修補截斷 JSON，拒絕重複鍵與非 JSON 常數。

恢復策略與預設值
設定預設邊界
tokens_per_minute00 = 停用本地 token 入場估算，429 等待仍有效。配給 100k TPM → 設 100000；預留 ≈ 輸入 + 請求輸出，以完整 usage 校正。
rate_limit_max_wait120 秒單次 client 呼叫的入場 + 429 等待共用上限（含 Qwen 備援）。依 Retry-After（秒或 HTTP 日期），缺則有限退避。耗盡 → 報錯；Ctrl-C 可中斷。
output_retries2最多額外 2 次乾淨嘗試；0 = 不重試。保留原始證據與已接受上下文；被拒文字不進新請求或修正提示。工作流程／Studio 另受 max_turns 限制。

同一 LLMClient 的主代理、文件子代理、壓縮呼叫、Qwen 備援共享 60 秒滾動預算與冷卻。缺 usage 或中斷的請求保留預留量至到期。屬 client／程序內估算，非供應者帳本，不跨程序共享。

Qwen 每次請求先用 qwen_backend；僅串流開始前失敗才有限切換 coordinator ↔ LiteLLM。首個 chunk 後不重播、不切換；中斷輸出整份丟棄，由代理乾淨重試。須有 finish reason，單獨 [DONE] 不算完整。上下文超限交給預算／壓縮。

CLI：--tokens-per-minute、--rate-limit-max-wait；三項皆可經 YAML 或 KENTC_AGENT_ 環境變數設定。文件重試另開 session；拒絕回覆、無關錯誤不通用重試。舊 session 不自動清洗；文件分塊尚無跨中斷續跑的檢查點。
