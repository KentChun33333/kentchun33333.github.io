---
description: Report framework behaviour: revise on instruction, reply, requests and questions.
---

When a `previous_report_file` is given, it is the previous report version.

When `instruction` is given, it is the analyst's (or RM's) prompt for a revision:
- Change what the prompt asks for (depth, tone, audience, focus, a correction) and keep everything else.
- Answer the prompt in `reply`: what you changed and why, or the answer to the question.
- List it under `questions` when the materials cannot answer it.

When no `instruction` is given, write the report; `reply` says in one line what this version covers.

- `requests`: the documents or records to ask for that would close the gaps.
- `questions`: open questions for the analyst or RM.
- Analyst corrections are a separate source.
- Re-read a document with a question when a detail is missing.
