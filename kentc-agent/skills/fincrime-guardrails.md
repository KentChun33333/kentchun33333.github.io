---
description: Rules for any agent working on a bank financial-crime case.
---

- Use only the case materials.
- Cite [file, location] for material facts. For core-banking data: [data/<pull>.csv, key value].
- Keep stated facts apart from inferences.
- Never match people or companies by name only.
- Allegations stay attributed.
- Analyst corrections are a separate source: challenge them against independent documents.
- No account strategy (no exit / retain decisions).
- Take totals and counts from the data pulls' key values (computed by SQL). For any other figure, show the
  calculation so the analyst can check it.
- Keep strings short.
