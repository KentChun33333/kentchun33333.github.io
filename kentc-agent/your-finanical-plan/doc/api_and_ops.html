1. Local PaddleOCR Microservice (Port 8866)

Hosts official PaddleOCR PP-OCR ONNX models (rapidocr) with HEIC/HEIF/WebM/JPG/PNG/WEBP decoding. Switchable to native paddleocr or Ollama MedAIBase/PaddleOCR-VL:0.9b in config.yaml.

cd your-finanical-plan
.venv/bin/python -m solutions.paddle_ocr_server
curl http://127.0.0.1:8866/health

2. FastAPI Sync Extraction Server (Port 8000)

Connects directly to local Qwen3.8 (:8081/v1) and local PaddleOCR (:8866).

cd your-finanical-plan
.venv/bin/python app.py
curl http://127.0.0.1:8000/health

API & Batch CLI Examples

# Sync API — CSV output (only name + file required; supports PDF, XLSX, HEIC, WEBM, JPG, PNG, WEBP)
curl -X POST "http://127.0.0.1:8000/extract" \
  -F "name=Kent Chiu" \
  -F "file=@dataset/sample_brokerage_iphone.heic" \
  -o extracted.csv

# Sync API — JSON envelope with optional document_type hint
curl -X POST "http://127.0.0.1:8000/extract?format=json" \
  -F "name=Kent Chiu" \
  -F "document_type=insurance" \
  -F "file=@dataset/scanned_insurance_65pages.pdf"

# Batch CLI — workers strictly bounded to 1..4 concurrent local Qwen3.8 calls
.venv/bin/python batch_run.py \
  --input-dir dataset \
  --output-dir outputs/run1 \
  --name "Kent Chiu" \
  --workers 4
