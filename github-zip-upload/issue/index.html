Upload through a GitHub Issue

Prepare a prefilled, owner-authorized upload request. GitHub hosts the ZIP attachment; an Action validates and extracts it into the hugo branch.

Open the prefilled issue
GitHub may ask you to sign in.
Drag one ZIP into the issue body
Wait until GitHub finishes inserting the attachment link.
Submit the issue
The Action accepts requests only from the repository owner, validates paths, commits the files, and comments with the result.

The Action must exist on the repository’s default branch (master) before Issue uploads can run.
