Private browser-side tool

Publish a ZIP to the Hugo branch

The archive is extracted in this browser, converted into one Git commit, and sent directly to GitHub. Your token stays in memory and is never stored by this page.

Waiting for a ZIP archive.
Safety and token scope
  • Use a fine-grained token limited to this repository with Contents: Read and write.
  • The archive may not contain absolute paths, .. traversal, .git, or files larger than 25 MiB.
  • This tool adds or replaces files. It does not delete files absent from the ZIP.
  • Close or refresh the tab to clear the token from memory.
