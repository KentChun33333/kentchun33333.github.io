Pi leads. The extension dispatches.

The lead owns the goal, decomposition, and final explanation. The example subagent extension starts separate Pi processes and brings their results back. Each child has its own model, tools, and context.

Independence determines concurrency.

Parallel tasks do not need each other's results. In a chain, agent B waits for A's output. The selector changes the message order and handoff; animation pace is unrelated to runtime speed.

Verification closes the loop.

The lead reconciles the results and runs relevant checks. The optional failed-check path adds a revision and a second check. This surrounding workflow is a proposed design.

Context isolation ≠ filesystem isolation. Separate agent contexts do not automatically create separate worktrees. Configure folders or worktrees when tasks may write overlapping files. This page explains a design; it does not connect to Pi or execute tools.
