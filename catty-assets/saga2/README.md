# 《夜局十二張》設計總覽（saga2）

**形式**：一章一檔（`chNNN.md`），柯南式週更——每章獨立事件，主線以「黑票」週週推進。

## 世界規則
主角 **Wei** 某夜搭上一班不存在的末班地鐵，車長收走他的手機、發他十二張黑票。規則印在票背：**每張票指定一場「局」——任何遊戲、任何賭注；贏了，蓋一章；十二章集齊，可兌現一個願望。** 每章 Wei 被丟進一個新世界，限期一夜完成票上的局。

## 三元素（每章必綁）
1. **性**：每章不同玩法，慢動作細寫（深度、角度、節奏計拍、收縮、呼吸），至少 40 句動作描寫
2. **活動**：每章一種遊戲／技藝，帶真實深度知識（籃球擋拆、德州範圍、麻將牌理、網球發球局…）
3. **事件＋主線**：當章事件勝負 ＋ 黑票進度、人物週更鉤子

## 主線週更鉤子
- 黑票蓋章進度（0/12 → 12/12）
- 宿敵 **K 先生**：同持黑票的資深玩家，專攪 Wei 的局，第 2 章現身影
- **車長**之谜：她似乎認得 Wei；願望的代價是什麼？
- 女性角色跨章回歸：上一章的人會出現在下一章的電視螢幕、牌桌、看台上
