# 第拾章 Ace

黑票翻面：**局：網球。一個發球局，保發。**

中央球場世界是夜場，燈白如晝，紅土細如磚粉。陸音是發球型選手，拋球穩如節拍器：「外鄉人，票上寫你發球。我教你一個發球局。」她授課：發球是唯一球在你手裡的球；一發吃力量，二發吃 kick——上旋加側旋，彈跳高、落點深；計分是 love、15、30、40，deuce 之後要連贏兩分；break point 是接發方的命，保發是發球方的命；接發要 split step，對手擊球瞬間墊步起跳；挑戰是最後的體面，鷹眼不講情面。Wei 第一個發球局雙誤被破；第二局他把二發 kick 進深區，救回 break point，發出一記 ace，保發，票過。

局休時她拉他進球員休息室，冰袋味濃。她摘了遮陽帽，頭髮散開，連球衣從頭頂摞下，只剩運動內衣。她反手解背扣，布料離體，乳房彈起，乳頭硬起。她把球裙和安全短褲一起褪下，腳跟退出，布料濕了。她坐上按摩床，兩腿分開，腳跟磕著床沿。他跪進她兩腿之間，雙手掐她胯。他低頭吻她大腿內側，嚐到磚粉的澀。指尖先繞陰蒂，兩拍、四拍、八拍，像計拍。她陰唇紅腫，在燈下發亮。他兩指插入蜷起壓前球壁，她 G 點在指下腫起來，叫了一聲，腰追他的手，床身晃動。愛液順指縫淌，滴上毛巾。

他站起來，抵住穴口画圈，她的穴口一開一合。她盤上他，腳跟壓上他腿彎。他緩慢推入，三分之一，她的穴壁一寸寸咬上來；三分之二，她臀部離床懸空；頂到底，恥骨壓住恥骨，兩人同時悶哼。她宮頸撞上他小腹，她抖：「這球——發得深。」他退到只剩槍頭，停兩拍，她腰回磨索要，他再整根貫入。

節奏一拍一停，淺、中、深。她乳房在床面上顛，乳頭磨出濕痕。他換角度，把她的膝壓向腋窩，深度變了，呻吟變調。「這球速，」她喘，「多少？」「二發。」他喘，「kick，落點深。」她穴壁收、放、收，對上他的節拍，他脊椎過電。她抓床沿，指節發白，毛巾滑到地上。他加速，每記頂進宮頸，整張床晃動，床腳磕得地板咚咚。她呼吸撞進他嘴裡，他吞掉。她先高潮，腳趾繡直，內側顫抖，愛液湧出澆濕他龜頭。

他把她翻過去，從後進入，掐住她胯。她臉側貼床面，呻吟悶著，聲響在休息室裡迴盪。節奏兩拍、兩拍，每記把她的臀撞回他胯上。她乳頭壓在身下磨得發顫。他掌根拍她臀，紅印開花，在休息室裡迴盪。他拽起她的頭髮，她仰背，槍頭從下頂進前壁，她叫出聲，指甲摳進床面。「break point，」她笑到喘，「這一分，你救回來了。」她穴壁收、放、收，他脊椎過電。她再高潮，全身痙攣，愛液順股溝淌進床縫。

他一記記射進她宮頸，掐住她的胯，頂住，不動。她穴壁餘韻地抽，把他最後一點絞出來。她額汗貼他額汗：「hold，」她喘，「保發了，發球先生。」他笑，撿起一顆球塞進她掌心，毛絨絨的，濕了一半。

按摩床邊，黑票自己蓋章：**10/12**。球場大螢幕切進攀石新聞：岩語 V9 首攀。K 先生坐在裁判椅上，把兩張黑票排成一列：「還剩兩張，小鬼。最後兩張——不在你手上，在車長手上。」廣播響起，這一次不是報站，是報時：「末班車——還有兩站。」
