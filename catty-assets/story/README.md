# 《膝與棋》一百章 — 設計總覽

**主角**：Wei（少爺，AI 資料副總裁→KneeGo CTO）× 林曜（25歲，國家隊退役體能教練→KneeGo Lab 創辦人）

## 核心三元素（每章必綁）
1. **性**：每章不同體位／玩法，動作力學細寫（深度、節奏、角度、收縮、呼吸）
2. **動作知識**：膝為主軸（力線、臀中肌、TKE、肌腱12週），延伸髖、踝、核心、恢復
3. **圍棋戰術**：每章一個真實術語（星位、掛角、劫、手筋、終盤…），棋力隨卷升級
