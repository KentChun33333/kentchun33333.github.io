# Guarded Skill Evolution

This folder contains a research proposal and interactive paper page for **Guarded Skill Evolution (GSE)**: a requirement-aware, regression-controlled approach to modifying persistent LLM-agent skills.

The central claim is simple:

> Skill evolution is a selective intervention problem. A reliable system must determine whether a skill should change, identify the actual failure owner, and require comparative evidence before promoting a new version.
