01 · Context Engineering

Orchestrate the active inference window.

The context window is a scarce execution surface. Stable prefixes, selective repository slices, and an append-only dynamic tail keep reasoning focused while improving cache reuse.

Atomic Memory Operations

CRUD, not transcript dumping.

Every incoming event should create, revise, invalidate, or ignore a memory record explicitly.

ADDCreate a new atomic fact when information is genuinely novel.
UPDATEMerge changed information into an existing record instead of duplicating it.
DELETEInvalidate facts contradicted by newer verified information.
NOOPDiscard temporary noise, pleasantries, and low-value state.
03 · Runtime

The dual-loop cognitive architecture.

The fast loop protects latency. The slow loop protects memory quality. Separating them prevents long-term maintenance from blocking user-facing execution.

04 · Implementation Blueprint

Build the stack in four moves.

The architecture can be implemented incrementally. Start with prompt stability, then compress code, consolidate memory, and finally improve retrieval diversity.

01

Lock the byte-0 system prompt

Keep identity, policy, tool definitions, and output contracts deterministically ordered and stable across related turns.

SYSTEM_PREFIX = stable(policy, tools, schema)
PROMPT = SYSTEM_PREFIX + memory_slice + dynamic_tail
02

Extract a code map

Parse repositories into signatures and dependencies. Load full implementation bodies only on demand.

class PaymentProcessor:
    def __init__(self, api_key: str): ...
    def process_charge(self, user_id: str,
                       amount_cents: int) -> ChargeResult: ...
03

Consolidate post-session facts

Convert raw traces into small, self-contained records with explicit operation, subject, evidence, tags, and importance.

{
  "action": "ADD",
  "subject": "codebase.convention",
  "importance_score": 0.9
}
04

Retrieve across multiple indexes

Fuse semantic, keyword, and graph candidates, then rerank for both relevance and diversity before prompt injection.

candidates = vector + keyword + graph
context = mmr_rerank(candidates, lambda_=0.7)
inject(context[:token_budget])
05 · Operating Principles

Five rules to keep the agent sharp.

Architecture quality comes from controlling what is remembered, what is retrieved, and what is allowed into the model at each turn.

Context is RAM; memory is SSD.Separate active reasoning from persistence.
Cache the prefix; vary the tail.Keep stable instructions deterministic.
Compress before injection.Prefer interfaces and structure over raw dumps.
Curate, don’t hoard.Small verified memories beat noisy archives.
Decouple maintenance.Keep consolidation outside the latency-critical path.
